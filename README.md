# RAG — Retrieval-Augmented Generation Projects

This repository demonstrates multiple **Retrieval Augmented Generation (RAG)** implementations focused on financial data analysis and generation.  
RAG systems combine **semantic retrieval** with **large language model generation** to answer queries grounded in document content.

---

## 🌲 Branch Overview

This repository is structured across multiple branches, each exploring a distinct RAG setup:

| Branch | Purpose |
|--------|---------|
| **main** | Project overview, instructions, and high-level design |
| **FinRag** | A financial RAG prototype built inside a Jupyter notebook with document indexing and response generation |
